## How to run

**Option A — SQL Editor (recommended without service role in agent):**

1. Apply `supabase/migrations/20261127120000_cup_ties_competition_and_labels.sql`.
2. Run `scripts/import-season/seed_2025_26.sql`.

**Option B — TypeScript importer:**

```bash
npx tsx scripts/import-season/import_season_2025_26.ts --dry-run
npx tsx scripts/import-season/import_season_2025_26.ts --apply
```

Requires `SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY`.

## Regenerate extracts / seed

